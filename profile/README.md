# Добро пожаловать в организацию DraimCiDo 👋

**DraimCiDo** — это Minecraft-проект, который развивается вокруг собственных игровых механик, серверной инфраструктуры и внутренних инструментов разработки.

Здесь находятся основные репозитории проекта, связанные с разработкой плагинов, правил, игровых систем и технической базы сервера.

---

## 📌 Что можно найти в организации

* 💡 **Разработка игровых механик**
  Основной фокус проекта — создание собственных систем для Minecraft-сервера: экономика, режимы, NPC, квесты, GUI, прогрессия игроков и другие игровые элементы.

* 🧩 **Основной плагин проекта**
  Центральная часть разработки ведётся в основном плагине, который используется как ядро для будущих и текущих режимов проекта.

* 📜 **Правила проекта**
  В отдельном репозитории хранятся основные правила Minecraft-проекта DraimCiDo.

* 🛠️ **Внутренняя разработка**
  Репозитории организации используются для работы над кодом, исправления ошибок, планирования обновлений и постепенного развития проекта.

---

## 📂 Активные репозитории

### 🧩 [DraimCorePlugin](https://github.com/Server-DraimCiDo/DraimCorePlugin)

Основной плагин проекта DraimCiDo, который разрабатывается по сей день.

В нём реализуются и дорабатываются ключевые системы проекта:

* игровые механики;
* экономика;
* GUI-интерфейсы;
* внутриигровые команды;
* системы прогрессии;
* интеграции с другими плагинами;
* функционал для будущих режимов сервера.

Этот репозиторий является центральной технической базой проекта.

---

### 📜 [rules](https://github.com/Server-DraimCiDo/rules)

Репозиторий с основными правилами Minecraft-проекта DraimCiDo.
